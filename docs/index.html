Comment les outils sont detectes
1. Script public

On inspecte le HTML public pour capter les tags charges en direct: CRM, analytics, chat, lifecycle.

2. Source officielle

On croise avec les pages d'integrations, docs, help center et pages produit de la startup.

3. Categorisation

Chaque outil est range en `CRM`, `Emailing`, `Support`, `Analytics` ou `Autres outils GTM`.

4. Prudence

Si un outil n'est pas visible publiquement, il reste `non detecte publiquement` plutot qu'invente.
